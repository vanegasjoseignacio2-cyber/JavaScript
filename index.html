¿Qué es JavaScript?

JavaScript es un lenguaje de programación que se ejecuta principalmente en los navegadores web. Permite añadir interactividad, controlar el comportamiento de una página y manipular el contenido que ves en pantalla. Es uno de los pilares del desarrollo web junto con HTML y CSS.

¿Cómo funciona?

JavaScript se ejecuta en un motor (por ejemplo, V8 en Chrome) que interpreta el código y lo convierte en instrucciones que la computadora puede ejecutar. En el navegador, JavaScript interactúa con el DOM para leer y cambiar elementos, responder a eventos y comunicarse con servidores.

También puede ejecutarse fuera del navegador (por ejemplo con Node.js) para crear servidores, herramientas y scripts.

¿Para qué sirve?

JavaScript sirve para crear páginas web dinámicas e interactivas: formularios que validan datos sin recargar, menús desplegables, animaciones, cargar contenido sin refrescar la página (AJAX / Fetch), y aplicaciones completas del lado del cliente. Con frameworks como React o Vue también se construyen aplicaciones web complejas, y con Node.js se desarrollan APIs y servidores.
